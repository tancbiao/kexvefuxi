## 技术规格

| 参数 | 值 |
|------|-----|
| 画布尺寸 | 2400 × 3600 像素 |
| 每格尺寸 | 240 × 240 像素 |
| 排列 | 10列 × 15行 = 150格 |
| 背景 | 纯白 #FFFFFF（PNG透明背景） |
| 风格 | 可爱Q版插画，2头身比例，色彩柔和，正面站立，带轻微描边 |
| 禁止 | 不要任何文字、编号、标签 |
