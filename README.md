# 科学趣味闯关

小学科学趣味复习系统，基于「最近发展区」理论设计。

## 目录结构

```
kexvefuxi/
├── index.html          # 年级/学期选择首页
├── 3/                  # 三年级
│   ├── 1/              # 上学期
│   └── 2/              # 下学期
├── 4/                  # 四年级
│   ├── 1/              # 上学期 ✓ 已上线
│   └── 2/              # 下学期
├── 5/                  # 五年级
│   ├── 1/
│   └── 2/
└── 6/                  # 六年级
    ├── 1/
    └── 2/
```

## 在线访问

访问地址：https://tancbiao.github.io/kexvefuxi

## 功能特点

- 游戏化闯关模式
- 三级难度递进（基础 → 提升 → 挑战）
- 分层提示系统
- 即时反馈机制
- 个性化学习报告

## 技术栈

- 纯 HTML/CSS/JavaScript
- 无需后端
- 可离线运行
