## 宠物积分云同步Bug — 根因确认（2026-05-20 17:53）

### 问题
宠物抽取后积分扣减，云存档同步后又回到最高分。

### 根因
**服务端 /data/api.py v705 "智能合并" 对 totalPoints 使用 Math.max(cloud, new)**，原本防止 0 分覆盖云端高分，但同时也阻止了宠物消费等合法积分降低。

### 调用链
pet-system → postMessage `pet_points_change` → index_v705 handler `gameState.totalPoints = reduced` → `saveUserData()` → `saveToCloud()` → POST API → **服务端 Math.max 拒绝降低** → 保留旧高分

### 修复方向
服务端修改 POST /api/student 端点：`totalPoints` 从 `Math.max(cloud, new)` 改为 `new==0 && cloud>0 ? cloud : new`（仅零分守卫，允许合法增减）
