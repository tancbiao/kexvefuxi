## 校队选拔推理测试模块 (commit `44d5bbd`, v710)

### 概述
在科学探险家平台新增「校队选拔」模块，60道图形推理题评估学生认知能力。

### 关键文件
| 文件 | 说明 |
|------|------|
| `xuanba.html` | 主测试页面（四屏：intro/test/result，SVG渲染，计时器） |
| `data/xuanba-questions.js` | 60题题库（6等级×10题，固定种子20260603） |
| `generate_xuanba.js` | 题库生成脚本（移植MIT开源rpm-iq-exam的puzzleGenerator） |
| `1/1/index_v705.html` | 集成按钮+iframe弹窗+postMessage |
| `admin/api_current.py` | API v710（xuanba save/load/ranking端点） |

### 技术要点
- **题目来源**: MIT开源 `yuis-ice/rpm-iq-exam` puzzleGenerator 移植到纯JS
- **渲染**: JSON→SVG 引擎（6种几何形状：circle/square/triangle/diamond/cross/star）
- **集成**: iframe弹窗模式 + postMessage双向通信（init_xuanba → xuanba_result）
- **计分**: 原始分60满 + IQ计算（加权平均+正确率调整，60-160范围）+ 正态分布百分位
- **限制**: 每人2次测试，保留最高分，同套题覆盖四五六年级
- **存储**: localStorage进度保存/断点续传 + 云端结果同步

### API端点
- `POST /api/xuanba/save` — 保存结果（最多保留2次，取最高分）
- `GET /api/xuanba/load/<sid>` — 加载历史
- `GET /api/xuanba/ranking` — 全校RA排行

## v710 第二次更新：RA推理指数 + 年级常模 + 排行榜 (commit `9477231`)

### 改动
- **RA推理指数**（60-160，同IQ分布但不叫智商）：基于学号提取年级→年龄常模表→百分位→标准分
- **年级常模**：四年级(22)→age9-10, 五年级(21)→age10-11, 六年级(20)→age11-12，各有独立百分位换算表

4. 分级：卓越(≥140)/非常优秀(≥125)/优秀(≥110)/良好(≥95)/中等(≥85)/偏低(≥75)/较弱(≥65)/需加强(<65)

## 装备赠送系统+亲密值+合成系统 (commit `8753b27`, v711)

### 功能概述 (由01200112提出)
在科学探险家平台新增三个社交化装备系统。

### 赠送系统
- **安全机制**: 接收方确认 + 24h撤回 + 每日限额(3件/天, 同对1件/天) + 消耗50积分
- **流程**: 装备详情→赠送→输入学号→扣积分→等待确认→双方亲密值+10
- **UI**: 礼物中心弹窗(收到/送出/亲密好友3个Tab)、红点提醒

### 亲密值系统
- **双向共享**: A赠送B, 双方各+10，每日首次互赠额外+5
- **5个等级**: 初识(Lv1/10)→好友(Lv2/50)→密友(Lv3/100)→挚友(Lv4/200)→灵魂伴侣(Lv5/500)
- **奖励**: 积分加成、掉落率、免费提示、史诗掉落翻倍

### 合成系统
- **规则**: 3件同稀有度装备 → 1件高1级(最高史诗5级), 传说/神话只能掉落
- **属性**: 基于3件材料平均值×稀有度倍率×(0.9~1.1随机)
- **类型**: 从3件输入装备中随机选择
- **限制**: 已装备/赠送中不可合成
- **UI**: 合成台弹窗(3槽位+预览+稀有度筛选+选择网格)
