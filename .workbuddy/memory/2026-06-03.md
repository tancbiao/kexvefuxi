## 2026科技节专属神话装备系统

从"2026科技节摊位征集.xlsx"（金山文档，35MB）提取了141名摊位工作人员名单，为每人生成了一件专属神话装备。

### 关键成果
- **装备数据**：`data/keji2026-equips.js` — 141件专属神话装备（其中138已通过student-names.js匹配学号，3人待手动关联）
- **奖励批次**：`admin/keji2026_rewards.json` — 138名已匹配学生的批量奖励数据
- **修改文件**：
  - `1/1/index_v705.html` — 加载装备数据 + 自动发放逻辑（grantKeji2026Equip）
  - `admin/reward-collector.js` — 支持完整装备数据(equipData)发放
- **Commit**: `782a2c3`，已推送 GitHub

### 装备命名格式
`第五届科技节优秀工作者{姓名}的专属神话{装备类型}`

### 装备属性
- 稀有度：神话（rarity=7），3.0x积分倍率
- 4属性词缀（暴击率/暴击伤害/经验加成/额外提示/跳过/连击/寻宝/满分等，每人随机3个）
- 属性值：120-200主属性 + HP/MP加成
- 每种装备类型在20种科学主题装备中通过名字hash分配

### 自动发放逻辑
学生登录后，奖励领取流程（collectPendingRewards）之后自动调用 grantKeji2026Equip()：
1. 通过 studentName 或 studentId 匹配装备列表
2. 防止重复发放（localStorage标记）
3. 添加到 gameState.equipment 背包
4. 显示通知

### 未匹配的3名学生
莫梓轩、黄梓玲、龚芷琪 — 需手动关联学号或创建游戏账号

- 通过金山文档 kdocs MCP 的 sheet API 读取数据
- 使用 git worktree 安全模式编辑大文件 index_v705.html
